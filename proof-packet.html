Primary work

Sarrus + FluxCell

Core technical work: Sarrus programmable soft robotic surfaces and bodies. Public record: sarrus.aolabs.io. FluxCell: actuation concept only where public sources support it.

  • Sarrus record: geometry, compliant link and flexural-joint path, pressure-driven expansion, constraint/bias, and module assembly.
